# dsh 成本与模型选型——峰谷定价 + 实测速查表（2026-08-26 实测，2026-10-24 复核更新）

> 定价来源：官方文档站 api-docs.deepseek.com/quick_start/pricing（2026-08-26 首抓；2026-10-24 复核——flash 降价、升级 V4.1-Flash-1017、新增 Search & Fetch 计费预告，详见文末"复核记录"）
> token 消耗：**真机实测**——dsh 0.1.0-rc.6 headless 三组对照任务 + 一个历史真实 Web 会话（131 步），并经账户余额扣费交叉验证（实扣 ¥0.13 vs 估算 ¥0.16，同量级）
> 人民币换算按 **¥7.2/$** 假设汇率，实际以支付渠道为准；v0.1 预览版接口常变，本文所有 API/行为描述基于 2026-08-26 调研（定价数字为 2026-10-24 复核价）

## 一、先说结论（TL;DR）

1. **新会话"固定税"≈ 1.5 万 token**：dsh 每次新会话第一步要注入 system prompt + 25 个工具定义 + 环境上下文，实测 13-15k input 全按 cache-miss 计费——flash 谷时约 **1.5 分钱**（10 月降价前约 3 分），问答类任务 98% 的 input 是这个固定税
2. **缓存是成本命门**：命中价只有 miss 价的 **1/50**（flash 新价谷 0.003 vs 0.15 $/M；Pro 为 1/30）。实测 10 步小任务里，后续每步 miss 仅百级、命中 1.5 万+；131 步长会话累计命中 1772 万 token 才 ¥0.38——**同样流量若无缓存，仅 input 一项就要 ¥19**
3. **Pro 单价 3-7 倍，总价不一定**：同一修 bug 任务，flash 走 10 步 ¥0.036（谷，新价折算），Pro 走 4 步 ¥0.086（谷）——贵 1.4 倍但快 3.7 倍（8/26 旧价时只贵 76%，flash 降价把价差拉回了一部分，Pro 的"步数效率"红利缩水）
4. **练手党黄金档 = 北京时间晚 18 点后 + 周末/法定节假日全天 + 工作日午休**：峰谷价差整整 1 倍，低谷窗口每天有 17 小时（节假日全天谷为 2026-10-24 版新增规则）
5. ¥45 余额 ≈ 谷时 flash 跑 **40+ 个"131 步级"长会话**，或 **1200+ 个小任务**——个人练手成本基本可以忽略（10 月降价后又能多跑约五成）

## 三、dsh 的 token 结构：每次会话的"固定税"

### 3.1 第一步请求里都有什么（headless 实测拆解）

从 request/header 抓到的第一步注入（standard preset，25 工具）：

| 组成 | 体量（字符） | 估算 token | 说明 |
|---|---|---|---|
| system prompt | 4,006（headless）/ 6,048（web） | ~1.2-1.8k | 身份声明 + 17 段工具使用守则（read/write/edit/glob/grep/bash/web_search/goal/subagent 纪律）+ 环境变量注入（checkout 路径、GUI 地址、cwd、模型名） |
| 工具定义 × 25 | 26,336（JSON） | ~7-8k | bash/read/write/edit/grep/glob/web_search/todo/skill/goal/subagent/workflow/ralph… |
| 环境注入 | 每项目不同 | ~5-6k | runtime context 快照、AGENTS.md workspace 指令、skill 清单 system-reminder |
| **合计（冷启动）** | — | **13-15k** | 三组实测第一步 miss：14,721 / 13,202 / 15,321 |

要点：

- **这部分全按 cache-miss 计费**（新会话无缓存可命中）：flash 谷 ≈ $0.002（¥0.014-0.016），Pro 谷 ≈ $0.009（¥0.06-0.07）——勘误：初版把这两个数错标成 ¥，实为美元，已按新价更正
- AGENTS.md 越大、skill 装得越多，固定税越高——**练手项目保持环境干净直接省钱**
- 对纯问答任务（1 步完成），固定税占 input 的 **98.5%**

### 3.2 缓存机制：多步会话的救命稻草

dsh 每步全量重发历史上下文（实测第 10 步 input 已达 18.5k），靠前缀缓存把重复部分按 1/30-1/50 价计费（Pro 1/30、flash 新价 1/50）：

| 实测（10 步修 bug 任务） | token | 说明 |
|---|---|---|
| 第 1 步 miss | 13,202 | 固定税 + 用户消息 |
| 第 2-10 步每步 miss | 48-489 | 只有新增内容按全价 |
| 第 2-10 步每步命中 | 14.8k-18.4k | 累计 146k 全走 1/30-1/50 价 |

结论：**只要会话不断，多步的边际成本极低**；反之，频繁开新会话 = 反复交固定税。

任务设计：T1 纯问答；T2/T3 同一个修 bug 任务（fib 边界错误，读文件→修复→pytest 验证），仅换模型。

## 五、速查表：什么任务用什么模型（核心交付）

| 场景 | 推荐 | 理由 | 预估单次成本（¥，谷/峰，2026-10-24 价） |
|---|---|---|---|
| **日常问答 / 概念解释** | flash | 单步完成，成本全在固定税；Pro 的智商在这类任务无增益 | 谷 0.01-0.02 / 峰 0.02-0.04 |
| **代码小改**（单文件修 bug / 小函数） | 两可：省钱 flash，省时间 Pro | flash 多走几步但单价低；Pro 步数少，总价差约 5 分-1 毛 | flash 谷 0.02-0.08 / Pro 谷 0.05-0.2 |
| **大型重构 / 难 debug**（跨文件、架构级） | V4-Pro | 推理质量 + 步数效率双优；flash 兜圈子的总 token 常反超（外推 30-60 步量级） | Pro 谷 1-3 / 峰 2-6 |
| **长会话**（连续多任务 1h+） | flash + 低谷时段 | 命中价 7.3 倍差距在百万级 hit 上放大：17M hit flash ¥0.38 vs Pro ¥2.8 | 单会话 1-2（flash 谷） |
| **批量 / 无人值守脚本** | flash + headless + 低谷 | 三重叠加：半价 × 最低价模型 × 无 UI 开销 | 单任务 <0.04 |
| **联网搜索 / 资料抓取任务** | flash，但盯次数 | web_search/fetch 走 server-side Search & Fetch API：11/1 前免费，之后 **$0.00075/次（≈¥0.005）**——搜索密集任务按次数另算 | 模型费同上 + 每次搜索 ¥0.005 |

选型口诀：**问 flash、改随便、重构 Pro、长会 flash 守着谷，搜索盯次数**。

## 六、峰谷策略：练手党实操

1. **黄金档**：工作日 18:00 后、周末与法定节假日全天、午休 12-14 点——每天至少 17 小时谷时（15h 夜间 + 2h 午休），赶上天假/长假等于全天谷价
2. **白天必须跑**：优先排 flash 小任务（绝对值差才几分钱）；把 Pro 重活攒到晚上
3. **充多少**：¥45 ≈ 40+ 个 131 步长会话（flash 谷）或 1200+ 小任务——**个人练手按 ¥50 充就够练一两个月**
4. **会话管理**：同一项目的关联问题塞进同一个会话（吃缓存），无关任务才开新会话（交固定税）
5. **环境瘦身**：练手目录别放大 AGENTS.md、少挂 skill——固定税随环境膨胀

## 七、省钱开关与已知坑（rc.6 实测踩到）

1. **credentials 写读格式 bug**：dsh 退出时把 `~/.dsh/.credentials.yaml` 重写为 `{version: 1(数字), refs: {...}}`，但启动校验要求顶层"key: 字符串"平铺——自产自炸。修法：启动前重置为 `DEEPSEEK_API_KEY: "sk-..."` 单行平铺（本文 wrapper 脚本 `/tmp/dsh_bench/dshr` 即为此生）
2. **headless 需要 `node --expose-internals`**：直接 `dsh --profile headless` 会因 HMR 插件初始化失败崩溃
3. **退出段错误**：headless 任务正常输出后以 rc=139/134 崩溃退出（free()/munmap invalid pointer）——cosmetic bug，不影响结果，判成功别看 exit code 要看输出
4. **thinking 默认 high**：flash 的 reasoning 占 output 约 67%（实测 T2），简单任务理论上调低 reasoningEffort 可省 output【配置项名与效果待实测】
5. 会话 jsonl 在 `~/.dsh/sessions/<cwd 转义>--/session-*/session.jsonl.zstd`，含逐步 usage（inputTokens/cacheReadTokens/outputTokens/reasoningTokens 四元组）——**对账/审计成本直接 zstd -dc 解析**
6. **Search & Fetch 11/1 起计费（2026-10-24 官网预告）**：dsh 的 web_search 工具走 server-side Search/Fetch API，11/1 前免费、之后 $0.75/千次成功请求——爬资料类无人值守脚本要重新算账，能合并/缓存查询就合并
