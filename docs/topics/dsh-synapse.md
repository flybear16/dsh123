# dsh-synapse —— 对话分支画布（会话地图）

> 把同一工作区的会话、追问和分支组织成一张可浏览、可拖拽、可缩放的地图；DSH 原生会话永远是唯一事实来源。数据复核 2026-11-17。

**热度**：liangmianya/dsh-synapse ⭐723；MIT；v0.5.6。鱼皮点评：「把对话变成画布，可从任意卡片拉分支，适合学习新知识；但目前不太稳定，偶有报错」。要求 DSH >= 0.1.7-rc.2（本版含破坏性变更，不兼容更早版本）+ Node ≥ 22.19.0。

## 是什么

DSH 的可视化对话工作台：顶部「对话 / 会话地图」开关进入。连续追问、原生 fork 出来的分支、不同会话，全部摆上同一张 canvas；卡片之间的连线**按 DSH 原生 fork 关系**连接——不另造一套会话历史。

| 能力 | 说明 |
|---|---|
| 对话地图 | 会话/追问/分支一张画布，可拖拽缩放 |
| 保留真实分支 | 只按 DSH 原生 fork 关系连卡片 |
| 追问顺手 | 选中回答中的文字直接带入新追问；常用补充词可编辑 |
| 双向同步 | 地图与原生对话切换会话，上下文保持一致 |
| 过程不挡路 | 工具调用按 `callId` 折叠成「工具 N」 |
| 详情侧栏 | 点卡片展开整轮：完整回答、工具过程、追问/分支/打开 DSH |
| 入口可挪 | 顶部开关可拖动、按浏览器记忆位置、双击复位、方向键微调 |
| 归档一致 | 归档集合地图与 DSH 侧栏共用一份 |

## 安装（注意 profile）

```bash
dsh plugin --profile desktop add dsh-synapse   # 桌面 App（装完重启 App）
dsh plugin --profile web add dsh-synapse       # 命令行 dsh web（重启并刷新）
```

自检口诀（README 原文）：**装完顶部看不到「会话地图」开关，就是装到另一套去了**——把 `--profile` 换成另一套再装一次。App 内插件页安装会自动进对 profile。

## 与 DSH 的边界（设计上很克制）

- DSH session log 保存真实会话内容；Synapse 只**投影**已提交的事件。
- 只存画布布局和每轮短预览，消息正文始终按需从 DSH 会话记录读取；`$DSH_HOME/synapse/` 删了不会丢会话，只丢布局。
- 不修改 prompt、模型请求、工具 schema、provider 路由、可复用 KV-cache 前缀——纯 UI 层插件，对[成本与模型选择](dsh-cost-and-model-selection.md)零影响。

## 风险与版本动态

- 稳定性是主要短板（鱼皮实测「偶有报错」）；0.5.6 修了一串交互一致性问题：切换会话带入视野、折叠卡片不再移动画布、工作区加载竞态（画布此前每秒重建数次）、`workspaces.json` 读不出时明确报错并保持只读（不再用旧备份覆盖原文件）。
- DSH 升级可能破坏其依赖的 Host 会话/Client 服务接口（0.1.7-rc.2 锚点）——升级 DSH 前看该插件兼容公告。

## CC 对照

CC 无等价物（对话分支画布依托 DSH 原生 fork 机制）；学习新知识、方案探索类会话值得装，长会话重度用户可配合 [billion-context](dsh-billion-context.md) 用（一个管空间结构、一个管 token 体量）。
