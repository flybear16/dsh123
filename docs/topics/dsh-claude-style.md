# dsh-claude-style —— DSH 变身 Claude Code Desktop

> 「你的下一个 Claude Code Desktop，何必是 Claude Code。」复刻 Claude Code Desktop 风格与交互的主题插件。数据复核 2026-11-17。

## 是什么

[Nwflower/dsh-claude-style](https://github.com/Nwflower/dsh-claude-style)（⭐622），npm 包 `dsh-claude-style`。装上后 DSH 界面整体变成 Claude Code Desktop 的观感——鱼皮原话：「这也太像了吧！」以及「不知为何，总有种账号随时可能被封的恐惧感」。

## 外观体系

- **品牌切换**：Claude / DeepSeek 双档，插件设置里一键换；亮暗跟随系统
- **六套配色预设**：Claude、DeepSeek、羊皮纸、森林、暮色、蔷薇——可编辑，也可新建、复制、重命名、删除多套方案
- 截图覆盖编程首页与对话界面，亮暗四态齐全

## 实测（鱼皮 11-06）

装上即变身，像到离谱。属于纯观感层插件，不碰会话数据，卸载即走。风险自负：用户对「界面像谁」负责，与上游无关。

## 注意

- 主题类插件随 DSH 版本迭代容易出样式兼容问题，更新 DSH 后留意
- 纯 UI 层，与 [dsh-pet](dsh-pet.md)、[dsh-whale-widget](dsh-whale-widget.md) 等功能插件不冲突，可叠装
