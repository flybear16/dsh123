# dsh-ppt —— 一句话做 PPT

> 给出材料，拿到可交付的演示文稿：HTML 放映 + 可编辑 PPTX + 工程包三件套。数据复核 2026-11-17。

## 是什么

[STARDUSTLC666/dsh-ppt](https://github.com/STARDUSTLC666/dsh-ppt)（⭐37），npm 包 `dsh-ppt`。别看 star 低，功能完整度超出预期：

- 生成 **HTML 放映、可编辑 PPTX 与工程包**
- 按需编辑文字、图片与页序，支持撤销
- 可选数字溯源、现场推演、AI 预审与**答辩演练**

## 实测（鱼皮 11-06）

输入：AI 闯关学习小程序的项目介绍。要求：面向大学生的 6 页 PPT。

流程：AI 先规划每页讲什么 → 制作 → 自查排版 → 交付网页版 + PPTX（**每页演讲者备注都写好了**），全程 **2 毛钱**。

效果：配色在线，项目截图、技术栈、功能清单位置都对。小瑕疵：第 1 页大标题最后一个「品」字被挤到第二行——好在有 PPTX，手动微调即可。

## 使用建议

- 材料给得越结构化，初稿越能用（别指望它替你做调研）
- 交付前过一遍 HTML 放映版看动线，再进 PPTX 修细节
- 对照：CC 生态做 PPT 要自己拼技能组合，这里是现成流水线
