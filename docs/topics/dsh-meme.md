# dsh-meme —— 表情包斗图

> 给 DSH 加表情包：自己点图发，也能让 AI 接着斗图——模型只输出文字标记，前端负责配图。数据复核 2026-11-17。

**热度**：yyh-001/dsh-meme ⭐581；MIT；Node ≥ 22.13。鱼皮点评：「给输入框加 24 张鲸鱼娘表情包，AI 竟然也能回表情包——在 AI 编程工具里也能斗图」。（README 现行内置图库为「大肥鱼图库 24 张」，与鱼皮文案同源）

## 是什么

| 能力 | 说明 |
|---|---|
| 一键发图 | 输入框旁 😊 选择器：搜索、按图库/情绪筛选、悬停预览、多选；点击聊天表情看大图（滚轮缩放） |
| 跟 AI 斗图 | 你发一张，AI 接着回一张——原理是模型在回复里写 `[表情: 描述]` 文字标记，前端只在其位置配图，**无需模型支持图片输入** |
| 情绪桶 | `happy / angry / sad / shy / confused / daily` 六桶 |
| AI 学新图 | 上传图片后说「把这张图入库」，`learn_meme` 自动识别分类与描述（需支持图片输入的模型） |
| IM 联动 | 经 dsh-im 接 QQ/微信/飞书/企业微信时自动改走原生图片消息（候选带绝对路径，模型调 `dsh_im_return_file` 投递，不写文字标记） |
| 图库市场 | 「发现」页一键安装/更新；ZIP 导入导出（SHA-256 校验）；投稿走 GitHub 表单人工审核 |
| 开箱即用 | 内置大肥鱼图库 24 张；零第三方运行依赖，用 Node 内置 SQLite |

## 工具与安装

两个模型工具：`send_meme`（`tag` 按情绪随机抽图 / `query` 按描述关键词搜索，范围为所有启用图库）、`learn_meme`（默认收录最近一张用户图片）。

```bash
dsh plugin --profile web add dsh-meme    # 或插件管理页「添加插件」输入 dsh-meme
```

旧包名 `dsh-expression` 已弃用（内部 ID 保留兼容）。默认扫描 `~/.dsh/meme-packs`，设置存 `~/.dsh/dsh-expression.json`，升级插件保留。

## 国内网络优化（值得一抄的设计）

图库目录托管在 GitHub，插件内置多镜像竞速：目录、清单、ZIP、逐图下载都会同时试原始地址和 ghfast.top / gh-proxy.com / ghproxy.net / cdn.jsdmirror.com / fastly.jsdelivr.net 等镜像，记住能用的；目录落磁盘缓存（断网先显示缓存并提示）；**镜像只换下载通道，SHA-256 对不上自动换下一个**——不会装进坏包。设置里可切「官方直连 / 国内镜像 / 自定义 catalog 地址」。

## 风险与边界

- 插件 HTTP 接口仅接受本机回环地址（localhost/127.0.0.1/[::1]），局域网访问被拒。
- 图库图片的版权与使用许可**按各图库单独说明**（插件代码 MIT ≠ 图片内容可随意商用）；投稿需声明图片来源与许可。
- 纯体验型插件：不改 prompt、不碰模型请求；token 开销仅来自候选列表注入的提示词，可忽略。

## CC 对照

CC 无等价物。「文字标记 + 前端配图」的斗图机制是 DSH Web 前端的能力；同样的 `send_meme` 思路在 CC 里没有渲染层可挂。想在 IM 里斗图需配套 dsh-im / dsh-companion。
