# dsh-meme —— 表情包斗图插件

> 输入框一键发图，AI 按聊天气氛接梗；图库能自己养，也能从市场装。数据复核 2026-11-17。

## 是什么

[yyh-001/dsh-meme](https://github.com/yyh-001/dsh-meme)（⭐581），MIT，npm 包 `dsh-meme`。给输入框加一个 😊 按钮：搜索或按图库/情绪筛选，点图直接发送。自带 24 张鲸鱼娘表情包（鱼皮实测口径），图库可扩展：

- **主动斗图**：AI 按聊天情绪自己找图接梗，四档可调（关闭 / 看气氛 / 活跃 / 每轮都发），提示词可改
- **学会新图**：上传图片说「把这张图入库」，AI 自动识别分类描述；拷进图库目录点「扫描新增」也行（GIF 保留动画）
- **整理图库**：`meme_list` / `meme_update` 让 AI 列清单、查重、改分类；删除留在面板防误删
- **管理分享**：多图库开关、ZIP 导入导出、[图库市场](https://github.com/yyh-001/dsh-meme-packs)一键安装

## 实测名场面（鱼皮 11-06）

发了一张一脸疑惑的鲸鱼娘，AI 竟然回了一张**转圈加载的表情包**。没想到在 AI 编程工具里也能斗图——写代码写累了跟 AI 互相发表情包解闷（前提是觉得 Token 花不完）。

## 进阶玩法

- 关掉「点图直接发送」后，点图只把 `[表情: 描述]` 插到光标处，随文字一起发
- 经 dsh-im 接 QQ / 微信 / 飞书后，表情包以原生图片消息发出（默认关）；QQ 大图可缩到 200–450px
- 手机经局域网 IP 打开 DSH Web 也能收发
