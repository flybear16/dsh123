# dsh-pet —— DSH 桌面宠物

> 一只住在 DeepSeek Harness 里的桌宠：一百余段透明动画、会聊天会报余额、还能让别的插件借它开口。数据复核 2026-11-16。

## 是什么

[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（⭐6,316）：待机呼吸、随机动作（打瞌睡、玩魔方、吃火锅……）、左右转向、屏幕漫游、点击 Q 弹、拖拽甩抛反弹、右键菜单点播——动画随时无缝衔接；还能跟随 DSH 会话事件切换工作状态动画、按档位播放余额动画 + 头顶气泡、碎碎念与对话聊天、窗口失焦弹系统通知。可多开同屏，能脱离浏览器住上桌面（透明置顶小窗），也能自己添加全新宠物种类（pet pack）。

## 三件套结构：不只是插件，是一条生产线

```
① 提示词（配方）   →  ② 素材生成链（引擎）     →  ③ 插件（成品）
AI 生成动画的配方      源视频 → 透明动画的管线      运行在 DSH 里的宠物
```

任何人 clone 本仓库，都可以从零生成自己的桌面宠物——换角色、换动作、换风格，全流程可复现。

## 安装

| 方式 | 命令/操作 |
|---|---|
| 图形化 | 「插件管理」页安装框填 `dsh-pet` |
| CLI（web 界面） | `dsh plugin --profile web add dsh-pet` |
| CLI（Electron 桌面版） | `dsh plugin --profile desktop add dsh-pet` |
| 独立模式（不装 DSH） | Release 下载 `dsh-pet-win-x64.zip`，双击 `dsh-pet.exe` |

装完**重启 DSH / `dsh web`** 才生效——运行中的进程持有内存里的旧插件。宠物默认落在界面右上角。

## 对外接口：给别的插件当「身体」

桌宠开放两条驱动通道，让其他插件或脚本能调用它——比如一个巡检插件检完想让桌宠开口播报结果：

- **HTTP**：挂在 DSH 自己的 Web 服务上（前缀 `/dsh-pet-7340`，**只监听本机、无鉴权**），跨进程、脚本可直接调；动作类接口只回 `{ok}`，数据统一从 `GET /state` 读
- **Cordis 服务**：同页客户端插件用 `ctx.get('petApi7340')` 直取，零网络、零端口，仅页面实例内有效

配套文档：`API.md`（HTTP 一览）、`openapi.yaml`（OpenAPI 3.1 完整契约，可导入 Swagger/Postman）、`CORDIS-API.md`（Cordis 成员一览）。

## CC 对照与注意事项

- **CC 对照**：Claude Code 生态无直接等价物，纯体验型插件。理念上它是「给 agent 一个可视化实体」的样板：状态联动 + 对外 API，值得写插件的人参考其接口设计
- **安全**：HTTP 通道无鉴权但默认仅本机监听，保持默认配置即可，别手动改监听地址暴露局域网
- **成本**：不碰 DSH 内核，卸载即走；动画素材百段视频占磁盘，留意体积；iOS 无振动 API 属平台限制
