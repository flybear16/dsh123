# dsh-pua —— 给 AI 上点强度

> 看似整活、实则管用：在 Agent 反复失败、过早放弃或草率宣告完成时，逼它换方法、查原因、拿证据。数据复核 2026-11-17。

## 是什么

[MichengAI/dsh-pua](https://github.com/MichengAI/dsh-pua)（⭐76），Apache-2.0，npm 包 `@michengai/dsh-pua`。将原版 [tanweai/pua](https://github.com/tanweai/pua) 带到 DSH 的社区移植。正经功能：

- **遇到困难换方法**：提醒重新检查思路，避免重复无效尝试
- **完成前检查证据**：核对结果，减少「说完成了但没验证」
- **验收 Loop**：启动循环让 Agent 持续修正，直到验收通过 / 轮次上限 / 手动取消
- **防作弊门**：拦截读取隐藏基准答案（含联网搜索）；变更测试、评分、CI 资产时向模型注入提醒
- 状态表/进度表/KPI 卡用 GFM 管道表，DSH 能直接渲染

## 风味系统

15 种大厂风味：阿里、字节、华为、腾讯、拼多多……到马斯克、乔布斯、Netflix；角色模式有 P7 / P9 / P10，甚至「夸夸」「妈妈」温柔路线。设置分两级：全局设置存插件，聊天入口单独调当前会话。

## 实测名场面（鱼皮 11-06）

让 AI 跑后端单元测试，故意补一句「跑不通就算了」。AI 发现缺依赖，真就顺坡下驴停工了。反手一个 `/pua again` 上强度——

AI 立刻支棱：先给失败定性，列出两条赛马路线（本机重建隔离环境 vs Docker 容器验证），规定各路线验收标准，最后总结：

> 赛马就赛两匹，一匹装环境，一匹进容器。哪匹先跑到 N passed，另一匹就下赛道。

味儿正。而且**它确实让 AI 少一点轻易放弃**——PUA 是表，验收机制是里。
