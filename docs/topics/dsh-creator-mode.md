# dsh 创造模式 —— 官方内置的「写插件的插件」

> 不是新模型、不是新应用：一个内置 Agent preset（内部 id `cordis`），换上运行时检查 + 插件管理工具，让 Agent 在对话里替你写插件、自己装、自己验。数据复核 2026-11-20。

## 是什么

与标准模式共用**同一个 Agent 循环、同一个模型、同一套权限系统**，区别只在工具箱：

| 工具 | 作用 |
|---|---|
| `cordis_inspect_list` / `cordis_inspect_query` | **只读**运行时检查：直接查看正在运行的服务、配置结构、工具结构、界面插槽——不用从源码猜 API；不能调用方法、不能执行代码 |
| `plugin_manager` | 插件管理：安装 bundle、检查插件实际状态 |
| （自动加载） | 插件开发 Skill：Agent 据此在工作区写插件文件，走「写 → 装 → 验」全流程 |

底层还是 Cordis（本站《[Cordis 元框架](dsh-cordis-framework.md)》那套）——官方把「写插件」本身做成了一个模式，inspect + 打包安装的工具交给 Agent，用户出嘴它出手。

## 生态数据与实测成本

- 截至 11-04（官方口径）：日活 154 万；第三方插件约 **3.5 万个**；约 **60% 活跃用户**制作或安装过至少一个第三方插件（dshmarket 单一市场收录近 9,000，见《[dsh-market](dsh-market.md)》，两口径不矛盾）
- @NFT_Chen 复现 3 个官方插件：3D 地标馆 21 分钟 **$0.38**、海报工作台 10 分钟 $0.1、会话统计 11 分钟 $0.16
- 投资界作者两个自造插件（提示词合计才 100 字）：鲸鱼娘 3D 马里奥 74 分钟；带「羁绊/心情/元气」属性的桌宠——缓存命中 99%，两件合计约 **6 元人民币**
- 体感：「许愿式编程」——描述最终成果即可，**描述越详细效果越好**；生成中需多次点「允许」，实验性自动审查插件也免不了

## ⚠️ 风险

- **写完直接安装**：Agent 生成代码后不经人工审查就装进 DSH——有 bug 或被恶意提示词诱导，可能伤及本机
- 建议在**不放个人凭据的一次性环境**（如临时 VPS）试玩（SSD Nodes 建议）
- 官方承认部分演示需多轮打磨；项目仍是开发者预览，README 大写警告 THERE WILL BE COMPATIBILITY-BREAKING CHANGES
- 目前**无官方插件市场**，只有实验性「自定义插件索引源」机制（见《[dsh-market](dsh-market.md)》）——创造模式的爆款可能倒逼官方市场落地

## 战略解读（Startup Fortune 角度）

创造模式与模型发布逻辑**供需相反**：发布模型是厂商往模型里塞技术，创造模式是用户先提需求再得到产品。DeepSeek 给骨架、用户和社区决定 DSH 的样子——界面是插件、工具也是插件。与其自己开发插件，不如让用户自己定义：使用者替 DeepSeek 造真正有需求的插件，再经插件市场分发，开源普惠落地成开发者生态。
